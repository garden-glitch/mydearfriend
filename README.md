🎁 우리반 마니또
교실 컴퓨터 한 대로 진행하는 학급 마니또 뽑기 웹앱입니다. 서버 없이 index.html 하나로 동작해 GitHub Pages에 바로 배포할 수 있어요.

사용 방법
선생님 모드 → 코드 1234 입력
명렬표 .txt 업로드 (한 줄에 한 명, 1. 김민준처럼 번호가 있어도 OK, 메모장 ANSI/UTF-8 모두 지원)
마니또 뽑기 → 처음으로
학생 모드 → 학생이 한 명씩 나와서 자기 이름 입력 → 마니또 확인 (15초 후 자동으로 닫힘)
선생님 모드에서 전체 연결 현황과 학생별 확인 여부 확인
특징
모든 학생을 하나의 원으로 연결 → 자기 자신이나 서로가 마니또가 되는 경우 없음
'한 번만 확인' 옵션으로 다른 친구 이름을 입력해 엿보기 방지 (선생님이 학생별로 재확인 허용 가능)
현황표의 마니또 이름은 기본적으로 흐리게 가려짐 (교실 화면 노출 대비)
주의
데이터는 그 컴퓨터의 브라우저(localStorage) 에만 저장됩니다. 뽑기와 확인은 같은 컴퓨터·같은 브라우저에서 진행하세요.
선생님 코드는 index.html의 TEACHER_CODE에서 바꿀 수 있습니다. 정적 사이트라 코드를 완벽히 숨길 수는 없으니 학급 활동 수준의 잠금으로 생각해 주세요.
GitHub Pages 배포
새 저장소에 index.html(및 이 README) 업로드
Settings → Pages → Branch: main / (root) → Save
잠시 후 https://<아이디>.github.io/<저장소이름>/ 에서 접속
